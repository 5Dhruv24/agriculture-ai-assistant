# 🌾 Agriculture AI Assistant

## About
A simple AI-powered agriculture assistant that provides
crop information, weather information, and AI-based farming guidance.

## Features
- 🌱 Crop Information
- 🌦️ Weather Information
- 🤖 AI Farming Assistant

## Technologies Used
- Python

## How to Run

1. Clone the repository
2. Install dependencies
3. Add required API keys
4. Run the application

## Project Structure

1.Crop data 
2.Mock weather data
3.Home screen
4.Crop Information screen
5.Weather screen
6.Ask AI screen
7.Navigation and styling
